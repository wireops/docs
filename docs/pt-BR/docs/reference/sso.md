# SSO com OIDC

O wireops pode autenticar contas por um provedor OpenID Connect, como Keycloak, Authentik ou Okta. Configure URL do emissor, ID e segredo do cliente e URL pública correta antes de habilitar o fluxo.

Teste o callback e a atribuição de perfis com uma conta não administrativa. Mantenha uma rota segura de administração local até validar o SSO e trate o segredo do cliente como uma credencial sensível.
