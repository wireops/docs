# Propostas de funcionalidades

O wireops é direcionado a GitOps para Docker Compose e não pretende se tornar um orquestrador Kubernetes, Swarm ou de autoscaling multi-nó. Consulte o arquivo de propostas no repositório para itens já entregues, ideias priorizadas e limites de escopo.

Uma boa proposta descreve o problema, usuários afetados, relação com o escopo, alternativa simples e como poderia ser testada. Verifique primeiro se o recurso já existe em integrações, políticas ou endpoints atuais.
